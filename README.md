# boltz-folding.demo.orchestrate.ca

A plain-English explainer on the MIT Boltz protein structure prediction models (Boltz-1 and Boltz-2).
Built live by the Orchestrate Solutions agent team in an Orchestrate demonstration. Static site: HTML, CSS and JavaScript, no build step.

## Pages
- `index.html`: Home
- `pages/protein-folding.html`: What is protein folding
- `pages/boltz-models.html`: Boltz-1 and Boltz-2
- `pages/how-it-works.html`: How structure prediction works
- `pages/why-it-matters.html`: Why it matters
- `pages/glossary.html`: Glossary and learn more

## Lanes
- Designer: `css/tokens.css`, `assets/`
- UI/UX: `css/layout.css`, `js/nav.js`, header/nav/footer
- Full-Stack: page content, `js/app.js`
- Lead Developer: scaffold, README, `css/site.css`
